# После уроков

Рабочий MVP планировщика для школьников. Полностью на русском.

## Запуск

В этой папке выполните `npm run dev`, затем откройте http://127.0.0.1:4175. Требуются Python 3 и Node.js для проверок. Приложение работает без установки зависимостей и без сервера данных. Не открывайте index.html напрямую: модулям нужен HTTP.

## Возможности

- Дела: создание, редактирование, дата, время, длительность, категория, заметки и отметка выполнения.
- Просроченные дела остаются видны в дневном плане. Поиск и фильтры доступны в разделе «Мои дела».
- Занятия: однократные и еженедельные, место, список подготовки, отметки посещения по датам.
- Предупреждения о пересечениях занятий, включая будущие повторения.
- Навигация по дням и неделям, оценка времени на оставшиеся дела.
- Сохранение в localStorage и обновление при изменениях в соседней вкладке.
- Резервные копии JSON с проверкой содержимого. Перед заменой плана скачивается текущая копия.
- Экспорт занятий и незавершённых дел в ICS. Поддержка VTODO зависит от приложения календаря.
- Напоминания за 15 минут, когда приложение открыто. Системные уведомления зависят от разрешения и поддержки браузера. Доставка при закрытой странице не реализована.
- Пример расписания добавляется явным действием в пустой план.

Данные хранятся отдельно в каждом браузере и на каждом адресе сайта. Синхронизация, общий семейный доступ, платежи и серверные push-уведомления не входят в MVP. Смена браузера или очистка хранилища требует восстановления из копии. Внешние веб-шрифты необязательны, предусмотрены резервные шрифты.

## Проверка

`npm test` проверяет даты, повторы, посещение, конфликты, напоминания, валидацию импорта и календарный экспорт. Перед публикацией дополнительно проверены пользовательские сценарии в браузере.

## Структура

`dist/` содержит готовый сайт без сборки, `tests/` содержит проверки. Это отдельный проект; исходный сайт в родительской папке не изменён.
